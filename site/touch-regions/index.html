    PDF view edge regions

    Use edge regions for seamless PDF interaction using finger touch gestures.

    Configurable actions

    Every touch region can be assigned the action that best fits your reading workflow.

    Three gestures per region

    Every region accepts a tap, long-press, or double-tap, with unique actions configurable for each gesture.

    Adjustable region size

    Touch region sizes are configurable, so the page edges can match your grip, hand size, and reading posture.

    Invisible while reading

    Touch regions are transparent during normal use. Show them only when configuring region sizes.

    By default, the eight regions work as paired left and right controls:

    R1

    Tap: Back to folder

    Double tap: Back to Home

    Long press: Show ToC

    R5

    Tap: Bookmarks

    Double tap: Show Settings

    Long press: Show Quick Access and Recent files

    R2

    Tap: Previous Page

    Double tap: First page

    Long press: Do nothing

    R6

    Tap: Next Page

    Double tap: Last page

    Long press: Do Nothing

    R3

    Tap: Previous Page

    Double tap: First page

    Long press: Do nothing

    R7

    Tap: Next Page

    Double tap: Last page

    Long press: Do Nothing

    R4

    Tap: Search Word

    Double tap: Crop to text

    Long press: Ask Action

    R8

    Tap: Show annotations

    Double tap: Show thumbnails

    Long press: Sync file

    How it helps

    Keep the document under your hands, like paper.

    The touch regions make common navigation targets available from the PDF view margins, so you can read, highlight, and annotate without reaching for toolbars or breaking concentration.
