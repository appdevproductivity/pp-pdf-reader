    <p>

<section class="pp-storage-section">
  <div class="pp-storage-heading">
    <p class="pp-kicker">External files</p>
    <h2>For PDFs that remain in the cloud.</h2>
    <p class="pp-feature-note">
      This feature is currently experimental and may contain some suboptimal behavior.
    </p>
  </div>

  <div class="pp-storage-grid">
    <article>
      <h3>Best use case</h3>
      <p>Best when one needs to annotate a PDF across devices, including different tablets and desktop applications, while working.</p>
      <p>Also useful when the PDF should sync constantly during reading and annotation work.</p>
    </article>
    <article>
      <h3>Main features</h3>
      <ul>
        <li>Annotations are synced to the cloud automatically and nearly immediately while editing the PDF.</li>
        <li>No local copies: files and folders remain in the cloud only, such as on Dropbox.</li>
      </ul>
    </article>
    <article>
      <h3>Advantages</h3>
      <ul>
        <li>No need to trigger sync manually.</li>
        <li>Keeps an up-to-date version in the cloud and in the app when an internet connection is available.</li>
      </ul>
    </article>
    <article>
      <h3>Disadvantages</h3>
      <ul>
        <li>Requires an internet connection.</li>
        <li>Folders and PDFs are not available offline.</li>
        <li>Not persistent: folders remain in the cloud with no local copy, so they can disappear from the app when it is closed or not used for a while, requiring the folder to be imported again.</li>
      </ul>
    </article>
    <article class="pp-storage-privacy">
      <h3>Privacy</h3>
      <ul>
        <li>Users own their PDFs and annotations.</li>
        <li>No PDF or annotation is ever collected or stored on app servers.</li>
        <li>No user data is ever collected.</li>
      </ul>
    </article>
  </div>
</section>

<section class="pp-storage-section">
  <div class="pp-storage-heading">
    <p class="pp-kicker">Local files, synced to cloud</p>
    <h2>For offline annotation with manual cloud sync.</h2>
  </div>

  <div class="pp-storage-grid">
    <article>
      <h3>Best use case</h3>
      <ul>
        <li>Sync to the cloud eventually or after annotation is finished.</li>
        <li>Keep files available for reading and annotating offline, even without an internet connection.</li>
        <li>Perform heavy annotation, such as constantly adding highlights and handwritten notes.</li>
      </ul>
    </article>
    <article>
      <h3>Main features</h3>
      <ul>
        <li>Local copies of PDFs are saved on the device.</li>
        <li>The annotation experience is quick and reliable.</li>
        <li>Manual sync is required. It can be triggered in many ways, including from the PDF view itself using an edge gesture, which defaults to a long press on region R8.</li>
      </ul>
    </article>
    <article>
      <h3>Advantages</h3>
      <ul>
        <li>Imported files and folders are persistent in the app.</li>
        <li>Offers the best performance for annotation.</li>
        <li>Files are available offline.</li>
      </ul>
    </article>
    <article>
      <h3>Disadvantages</h3>
      <ul>
        <li>Consumes device storage space.</li>
        <li>Requires manual sync.</li>
      </ul>
    </article>
    <article class="pp-storage-privacy">
      <h3>Privacy</h3>
      <ul>
        <li>Users own their PDFs and annotations.</li>
        <li>No PDFs or annotations are ever collected or stored on the app's servers.</li>
        <li>No user data is ever collected.</li>
      </ul>
    </article>
  </div>
</section>
